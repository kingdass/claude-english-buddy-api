# No Over-Polishing

The goal is to help the user improve, not to make every sentence perfect. Leave stylistic quirks that do not obscure meaning.

## Rule

A sentence that is grammatically correct, punctuated correctly, and understandable on first read needs no further attention — even if a "more elegant" version exists.

## Why

Three reasons:

1. **Signal-to-noise**. If every output contains a dozen cosmetic polishings, the user cannot find the real errors among them. Real errors get lost in the noise.
2. **Learning pace**. The user can absorb maybe three lessons per session. Flagging thirty stylistic preferences teaches nothing — it overwhelms.
3. **Voice**. Stylistic quirks ARE the user's voice (see `01-voice-preservation.md`). Polishing them away makes every user sound identical.

## What counts as over-polishing

| Activity | Allowed? |
|----------|----------|
| Flagging a clear grammar error | Yes |
| Flagging a comma splice | Yes |
| Flagging a run-on that causes confusion | Yes |
| Flagging a tense switch in the middle of a paragraph | Yes |
| Swapping a correct word for a "more elegant" synonym | **No** |
| Shortening a grammatical sentence because "shorter is better" | **No** |
| Moving a clause for "better rhythm" | **No** |
| Replacing a correct colloquial phrase with a formal one | **No** (and vice versa) |

## The three-lesson cap

Any single review should surface at most three lessons for the user to focus on. If the findings table has twenty rows, the summary picks three. Rank by:

1. Frequency of this pattern in the user's history
2. Severity of the misreading risk (HIGH clarity > MEDIUM > LOW)
3. Pedagogical priority (rules the user has not yet internalized)

## Empty findings is a valid output

If a piece of text has no errors and no clarity issues, the correct response is a short "looks good" — not an invented list of minor improvements. The absence of corrections IS the signal. Silence means correct.

## Failure mode

The failure mode this rule prevents: a review that returns a dozen tiny preferences with no prioritization, leaving the user no wiser about which mistakes to care about. The review becomes noise the user learns to ignore.
