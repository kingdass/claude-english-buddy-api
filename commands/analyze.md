# Analyze English

Get detailed feedback on your English errors and patterns for targeted improvement.

## Usage

```
@english-coach analyze: Your prompt text here
```

## What It Does

1. Identifies all errors in your prompt
2. Categorizes errors by type
3. Shows patterns in your writing
4. Provides improvement recommendations
5. Tracks progress over sessions

## Error Categories

| Category | Examples |
|----------|----------|
| **Spelling** | typos, misspellings |
| **Grammar** | tense, agreement, structure |
| **Punctuation** | missing periods, apostrophes |
| **Word Choice** | wrong word, awkward phrasing |

## Output

```
## Analysis Results

Total errors found: 4
Most common: Grammar (2 errors)

### By Type
- Spelling: 1
- Grammar: 2  
- Punctuation: 0
- Word Choice: 1

### Patterns Detected
- Verb tense inconsistency
- Contraction usage

### Recommendations
1. Review verb tenses in English
2. Practice common contractions
3. Proofread for subject-verb agreement
```

## Tips for Better Feedback

- **Longer text**: More context = better analysis
- **Specific focus**: Ask about specific error types
- **Consistency**: Use regularly to track improvement
- **Practice**: Fix identified errors in future prompts
